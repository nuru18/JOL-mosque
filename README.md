# Центральная мечеть — собранный сайт

Готовая страница концепт-редизайна сайта **Центральной мечети имени
имама Сарахси** (Бишкек).

> Концепт-редизайн, неофициально. Данные — из публичных источников
> и карточки 2ГИС.

## Публикация на GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: **main**,
папка **/ (root)** → Save.

Важно: сборка запускается по пушу. Сначала включите Pages, и только потом
делайте коммит — иначе публикация не стартует.

Адрес: https://nuru18.github.io/JOL-mosque/
(регистр в адресе имеет значение)

## Что внутри

Расписание намазов на сегодня с обратным отсчётом до ближайшего,
исламская дата, галерея, разделы о мечети и как добраться.
Всё в одном файле: фотографии вшиты в страницу, внешних запросов нет.

## Стек

Статический HTML + CSS + JavaScript, без сборки.
Время намазов — Aladhan API, исламская дата — `Intl.DateTimeFormat`
с календарём `islamic-umalqura`.
